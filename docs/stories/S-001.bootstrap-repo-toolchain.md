# S-001: Bootstrap del repositorio y toolchain

**Status:** Completed
**Created:** 2026-08-27
**Source:** REQ-001

## Historia de Usuario

**Como** desarrollador del conector de mail,
**quiero** un repositorio inicializado con el toolchain que el SDK del bus impone (Node ≥ 22.12,
TypeScript 5.x `strict`, ESM) y una suite de tests que puede levantar un NATS real,
**para** que todo el resto del conector se escriba sobre una base que compila, tipa y se testea
desde la primera línea, sin descubrir tarde que el SDK no carga.

## Criterios de Aceptación

### CA-1: El proyecto compila con el toolchain impuesto por el SDK

**DADO** el repositorio recién inicializado
**CUANDO** se corre la compilación de TypeScript
**ENTONCES** compila sin errores con `strict: true` y `noUncheckedIndexedAccess: true`
**Y** el `package.json` declara `"type": "module"` (ESM)
**Y** el campo `engines.node` declara `>=22.12` — el floor que impone `@gravadigital/jiku`
**Y** la versión de TypeScript es 5.x.

### CA-2: La dependencia del SDK está declarada y se importa

**DADO** el `package.json` del conector
**CUANDO** se inspeccionan las dependencias
**ENTONCES** `@gravadigital/jiku` está declarado en `^1.0.0`
**Y** un import del SDK resuelve y tipa correctamente en un archivo ESM.

### CA-3: La estructura de carpetas sigue la convención base

**DADO** el repositorio inicializado
**CUANDO** se inspecciona `src/`
**ENTONCES** existen los cuatro directorios `src/config`, `src/domain`, `src/infra` y `src/shared`
**Y** `src/domain` contiene los tres módulos declarados en el manifest: `ingesta`, `ruteo`,
`publicacion` (vacíos o con placeholder: `ingesta` y `ruteo` se llenan en FG-2 y FG-3).

### CA-4: Los imports absolutos `@/` resuelven

**DADO** un módulo que importa otro con la forma `@/shared/...`
**CUANDO** se compila y se ejecuta
**ENTONCES** el import resuelve tanto en la compilación de TypeScript como en tiempo de ejecución
(el mapeo está configurado en los dos lados, no sólo en `tsconfig.json`).

### CA-5: Vitest corre con un solo contenedor NATS

**DADO** la suite de tests configurada
**CUANDO** se ejecuta la suite completa
**ENTONCES** el `globalSetup` levanta **un solo** contenedor NATS reutilizado por todos los archivos
**Y** `fileParallelism: false` está configurado, para que dos archivos no compitan por el mismo
contenedor
**Y** un test de humo que se conecta a ese NATS con `Client.fromConnection()` pasa.

### CA-6: Prohibiciones de dependencia verificables por ausencia

**DADO** el `package.json` del conector
**CUANDO** se revisan todas las dependencias, directas y de desarrollo
**ENTONCES** **no aparece** `nats` como dependencia directa (lo trae el SDK)
**Y** **no aparece** ningún cliente de PostgreSQL (`pg`, `sequelize`, `sequelize-typescript`,
`typeorm`, `prisma`, `knex`)
**Y** **no aparece** ningún cliente de storage (`@aws-sdk/client-s3` o equivalente).

### CA-7: Los scripts del repositorio están declarados

**DADO** el `package.json`
**CUANDO** se inspeccionan los scripts
**ENTONCES** existen al menos los de build, test y `start`
**Y** existe un script separado para el modo de verificación (implementado en S-005), de modo que
**`start` nunca publique un comando como efecto secundario**.

### Flujo de Interacción

#### Escenario: Compilación y ejecución de la suite (CA-1, CA-5)

**Trigger:** `npm run build` / `npm test` en el repositorio recién inicializado.

**Flujo:**

1. **[jiku-mail-connector · `tsconfig.json`]**
   - Acción: compila `src/` con `strict: true` y `noUncheckedIndexedAccess: true`, resolviendo los
     imports absolutos `@/`.
   - Output: build limpio, sin errores de tipo.

2. **[jiku-mail-connector · Vitest `globalSetup`]**
   - Acción: levanta **un** contenedor NATS con Testcontainers y expone su URL a los tests.
   - Output: URL del NATS efímero disponible para toda la suite.

3. **[jiku-mail-connector · test de humo]**
   - Acción: se conecta al NATS del contenedor con `Client.fromConnection()` del SDK, que **saltea el
     handshake de auth** a propósito.
   - Output: cliente construido; el test verifica que el SDK carga y tipa en ESM.

4. **[Vitest `globalSetup` teardown]**
   - Acción: baja el contenedor al terminar la suite.
   - Output: sin recursos colgados.

**Outcome:** el repositorio compila con el toolchain impuesto por el SDK y la suite de tests puede
hablar con un NATS real. No hay configuración, ni logger, ni conexión autenticada todavía.

**Manejo de errores:**
- Node < 22.12 en el entorno → `npm install`/`npm ci` falla por `engines` antes de compilar.
- Import del SDK que no resuelve (CJS vs ESM mal configurado) → falla la compilación, que es
  exactamente el punto: se descubre acá y no en el despliegue.
- Contenedor NATS que no arranca (sin Docker disponible) → falla el `globalSetup` con un mensaje que
  identifica la precondición, no un timeout mudo de cada test.

### Flujos Afectados

Ninguno. Esta story no produce comportamiento observable en el sistema: prepara el terreno. Los dos
flujos del producto —**arranque-y-conexion-al-bus** y **publicacion-requirements-new**— los crean
S-004 y S-005.

### Consideraciones Técnicas

**Seguridad:**
- Ninguna credencial entra en esta story: no hay lectura de entorno (S-002) ni identidad (S-004).
- Las prohibiciones de dependencia (CA-6) son la primera línea de NFR-S04: sin cliente de BD y sin
  cliente de storage, **no hay credenciales de base ni de S3 que filtrar**. Verificable por ausencia.
- `nats` no se declara directo (ADR-002): una versión distinta a la que el SDK espera rompe el
  protocolo de forma silenciosa.

**Performance:**
- Un solo contenedor NATS en `globalSetup`, no uno por archivo: levantar un contenedor cuesta
  segundos y multiplicarlo por archivo hace la suite inusable.
- `fileParallelism: false` es un costo de tiempo aceptado deliberadamente — es lo que hace
  determinista compartir un único contenedor.

**Dependencias:**
- **Prerequisitos:** ninguno. Es la primera story del producto.
- El `engines` floor y ESM **no son preferencias**: los impone `@gravadigital/jiku` ^1.0.0 (ADR-002).
  Fijarlos acá evita que S-002 a S-006 se escriban contra un target equivocado.
- **Todas las stories siguientes dependen de esta**: nada compila antes.
